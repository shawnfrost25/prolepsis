## Concepts utility
This section was primarily created to help me explain various concepts to myself, particularly those whose underlying architecture I haven't fully grasped. It will contain explanations, Mermaid diagrams, and code examples.

The presence of a concept here doesn't necessarily mean I'm new to it. Rather, it means that, while coding, I noticed something didn't quite add up. For example, a concept might behave differently from what I previously understood, or its actual implementation might contradict my mental model of how it works.

In other words, these are concepts I thought I understood but apparently hadn't fully grasped.
