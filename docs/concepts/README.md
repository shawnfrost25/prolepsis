## Concepts utility
I created this section primarily to help explain various concepts to myself, particularly those whose underlying architecture I haven't fully grasped. It contains explanations, Mermaid diagrams, and code examples.

The presence of a concept here doesn't necessarily mean I'm new to it. Rather, it means that, while coding, I noticed something didn't quite add up. For example, a concept might behave differently from what I previously understood, or its actual implementation might contradict my mental model of how it works.

In other words, these are concepts I thought I understood but apparently hadn't fully grasped. The presence of "//" in an explanation indicates that part of the explanation is missing because it wasn't necessary—for example, there is no reason to provide a diagram for something as simple as an interface. However, when "//" appears under "What I Still Don't Understand," it indicates that I currently have no questions about the concept or how it works, while acknowledging that something may arise in the future that requires further investigation.
