## Visualization Utility
* This folder has a simple purpose: to provide diagrams created with **[Mermaid](https://mermaid.js.org/)** so that any engineer can easily understand the process behind each handler without having to learn Go or Rust just to understand how it works. Each visualization folder contains diagrams for the handlers belonging to that part of the project.

## Currently Available Visualizations
* **kitanai** -> Contains the visualizations of the Kitanai handlers. [CLICK ME](https://github.com/shawnfrost25/prolepsis/tree/main/docs/visualization/kitanai)
- **github** - Contains the visualizations of the GitHub handlers. [CLICK ME](https://github.com/shawnfrost25/prolepsis/tree/main/docs/visualization/github)
